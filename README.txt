Splash Sort: build with GitHub Actions
1. Upload ALL files and folders (including the hidden .github folder) to a new GitHub repository, branch main.
2. Open the Actions tab > Build APK > Run workflow (it also runs on every upload).
3. When the run is green, open it and download the artifact SplashSort-debug-apk (a zip containing app-debug.apk).
4. Install app-debug.apk on your phone. In the game: Settings > Ad status.
